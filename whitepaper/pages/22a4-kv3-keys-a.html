Keys: vault-based patterns

Keys - Patterns 1-3 use vaults. Compare Microsoft-managed recovery with independent regional vaults; confirm the consuming service supports the topology.

1Standard or Premium vault + paired-region replication
Origin
Generate in the primary vault: Standard for software protection; Premium for HSM protection.
Outage
Read-only after Microsoft-managed failover. No key creation or rotation.
Best for
Services accepting Microsoft recovery timing; choose the tier for key protection.
Watch for
Eligible pair only. Premium does not improve regional recovery control.
2Standard or Premium vault in each region
Origin
Generate a different key in each Standard or Premium vault.
Outage
Full local read and write in the surviving region.
Best for
Services allowing independent regional keys.
Watch for
Not separate keys for replicas of one GRS storage account.
3Premium vault per region + external HSM / BYOK
Origin
Customer-owned external HSM; import into each vault.
Outage
Full local read and write in the surviving region.
Best for
External key origin with independent regional vaults.
Watch for
Pattern 2 service constraints; coordinate imports and rotation.

Key origin is not the same as recovery

CMKs protect a service data encryption key. Standard supports software-key import; the HSM-to-HSM BYOK transfer patterns use Premium or Managed HSM. Importing the same material into two vaults does not automatically make a service support two vaults. Preserve required historical key versions.
