1Self-Contained Workloads
Self-contained workloads with no persistent private dependency outside the workload. These can include cloud-native or AI applications.
  • No persistent private dependencies
  • Can often use No platform
  • Flexible placement across regions
Typical Platform Services profiles
No platformRemote platformMinimal platformFull platform
2Selectively Connected Workloads
Workloads that reach selected services through private endpoints or specific private APIs, without routed access to the enterprise network.
  • Private access to selected dependencies
  • Profile set by latency, traffic, resiliency, security
  • Common for data, analytics, and AI platforms
Typical Platform Services profiles
Remote platformMinimal platformFull platformNo platform
3Hybrid-Dependent Workloads
Workloads that need routed access to on-premises environments or the enterprise network, including shared platform services hosted or connected to a network hub.
  • Persistent private connectivity
  • Profile set by dependency latency, resiliency, regulation, operations
  • Common in migrations and hybrid scenarios
Typical Platform Services profiles
Remote platformMinimal platformFull platform
4Interdependent Workload Groups
Groups of workloads with material east-west dependencies: shared data, synchronous calls, or private east-west traffic. Combine members' requirements.
  • Classified at group level
  • Aggregate requirements set the profile
  • Direct spoke-to-spoke or a regional network hub for east-west traffic
Typical Platform Services profiles
No platformRemote platformMinimal platformFull platform
